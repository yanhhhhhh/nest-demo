# MCP Server

## Model Context Protocol (MCP)

MCP 是由 Anthropic 开发的开放标准协议，旨在让 AI 助手能够安全、可控地访问外部数据源和工具。它解决了传统 AI 助手功能单一、无法扩展的核心问题。

### Sequential Thinking

#### 介绍

> Sequential Thinking 是 MCP 的一个关键特性，允许 AI 助手通过一系列步骤来处理复杂任务。每个步骤都可以调用不同的工具或数据源，最终将结果整合起来。
> 通过结构化思维过程提供动态和反思性问题解决的工具

#### 适用场景

- 复杂问题分解（如系统设计、项目规划）
- 需要中途修正或多路径探索的分析任务（如架构选型、方案对比）
- 信息过滤与优先级排序
- 迭代开发与持续优化

### Context7

#### 介绍
Context7 是 MCP 的另一重要特性，允许 AI 助手访问和处理大量上下文信息。它支持多种数据格式和来源，使助手能够更好地理解和利用外部信息。
#### 适用场景
- 大规模文档处理与分析（如法律文件、技术文档）
- 多来源数据整合与洞察（如市场调研、用户反馈）
- 复杂知识图谱构建与查询
- 实时数据监控与响应（如金融市场、社交媒体）
#### 使用示例
使用use context7关键字调用Context7功能，传入大量文本数据，AI助手能够基于这些数据进行回答和分析。

### Playwright MCP

#### 介绍

让AI大模型（如Copilot、Claude等）能够通过结构化数据与网页进行交互，实现自动化操作，无需依赖视觉模型或截图识别。

#### 应用场景

- AI 助手自动化网页操作（如 Copilot、Claude 等）
- 自动化测试、数据采集、表单填写
- 无需视觉模型即可实现网页交互
- 文件上传下载、批量操作等自动化需求
